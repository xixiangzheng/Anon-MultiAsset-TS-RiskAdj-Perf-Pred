### Phase 8: 提交 mega2_ens → 失败诊断
**关键发现**：把 holdout 分早晚两段，ratio_cb 类模型提升是晚段 leak：
| 模型 | 早段(似公榜) | 晚段(含 leak) | Δ(晚-早) |
|---|---|---|---|
| raw_cb | 0.00176 | 0.00150 | -0.00025（正常）|
| **ratio_cb** | **0.00169** | **0.00194** | **+0.00025（leak!）** |
| ratio_cb_deep | 0.00157 | 0.00181 | +0.00024（leak!）|
| **ratio_lgb** | **0.00180** | 0.00171 | -0.00010（稳健）|
| nn3_emb32 | 0.00178 | 0.00130 | -0.00049（正常）|

**根因**：ratio_top50 用 part0+1 搜，holdout 含 part0+1 末段 → ratio_cb 在 holdout 虚高。

### Phase 9: 早段优化权重 → early_ens_H
- 用早段 holdout 优化，避免 ratio_cb
- 配方：ratio_lgb:0.15 + cb:0.22 + xgb:0.17 + nn3:0.46
- 早段 R²=0.002049（看似好）
- **公榜 0.003207**（仍失败）❌
- **原因**：ratio_lgb(top-50) 仍是 partition-specific，不如 ens_ratio_nn30 的 simple ratio(÷157)

### Phase 10: 已验证候选集成 → verified_avg3
- 等权平均 3 个已验证候选（0.003345 + 0.003320 + 0.003313）
- 三者相关性 0.99+（高度相关）
- **公榜 0.003337**（≈ 持平，-0.000008）
- **结论**：已验证候选平均无法超越最强单候选

### Phase 11: ratio 信号 partition-specific 的最终验证
- 用 part3+4（不同分区）搜 ratio → top 相关 **仅 0.021**（vs part0+1 的 0.034）
- 最佳分母不同（feature_159 vs feature_157）
- ratio_cb150 holdout 0.00167（< ratio_cb 0.00182）
- **铁证**：ratio 信号是 partition-specific 噪声

## 核心教训

### 1. holdout 优化严重过拟合公榜
- mega2 holdout 0.002083（+6%）→ 公榜 0.003186（-5%）
- 早段优化也过拟合（early_ens_H 仍失败）
- **holdout 与公榜的分布差异是根本问题**

### 2. ratio 扩展全部失败
| 方向 | 结果 |
|---|---|
| top-50 ratio (vs simple ÷157) | partition-specific，公榜更差 |
| ratio_cb | 晚段 leak 假象 |
| ratio_nn_emb32 | 公榜差 |
| sum/diff/three-way 交互 | 模型已自学，无效 |
| 大 NN / stacking / ExtraTrees | 全失败 |

### 3. 公榜是唯一真理
- ens_ratio_nn30 (simple ratio_lgb + raw_cb + nn) = 0.003345 是真信号
- 所有复杂化都让公榜变差
- **简单 = 稳健 = 公榜好**

### 4. 0.003345 可能是真实天花板
- target 是 innovation 噪声墙（用户已确认）
- ratio 信号 partition-specific（今日验证）
- 已验证候选平均无法超越最强单候选
- **0.0037 在当前数据下不可达**
