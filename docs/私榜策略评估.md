# 私榜策略评估（4 核 / 50ms 超时风险）

> 2026-08-10。私榜=提交策略代码，官方在 4 核 CPU / 12GB / 无 GPU / 无网、单步 ≤50ms、模型加载 ≤180s 下跑未来 9 月数据。

## 本地测量（服务器高争抢，**非代表性**）

tuned LGBM 单步 predict（batch≈15 行）：

| 配置 | 单步耗时 | 说明 |
|---|---|---|
| 单模型(448 轮), nt=1/2/4/8 | ~19ms | num_threads 无影响 → 瓶颈是 CPU 占用率，非线程开销 |
| 3 模型完整(448r×3 seed) | ~57ms | 超本地表现，但被争抢膨胀 |

**对照基准**：baseline LGBM(173r×3seed) 早先在同一服务器推理实测 **3.7ms/step**（含历史循环）。tuned 树量是 baseline 的 2.6×，理论应 ~9.6ms，但本地测出 57ms → 当前争抢比 baseline 实测时严重约 6×。

## 推算真实评估环境（专用 4 核，不争抢）

| 策略 | 推算单步 | 50ms 余量 | 私榜可行性 |
|---|---|---|---|
| baseline LGBM (173r×3) | ~1-2ms（参考实测 3.7 含争抢+历史循环） | 25×+ | ✅ 极安全（官方原版） |
| tuned LGBM 单模型 (448r×1seed) | ~2-4ms | 12×+ | ✅ 安全 |
| tuned LGBM 3 模型 (448r×3seed) | ~5-10ms | 5-10× | ✅ 大概率安全 |
| **集成 LGBM+CatBoost** | ~15-25ms | 2-3× | ⚠️ 偏紧，max 可能触 50ms |

⚠️ 以上为推算，本地无法用专用核干净复现（服务器共享争抢）。真实评估需在接近 deadline 时用 `taskset` 限定 4 核 + 低争抢时段复测，或直接相信"专用核 >> 共享核"。

## 核心策略判断（结合噪声墙）

**关键事实**：tuned ≈ baseline（CV 0.00211 vs 0.00209，全量没迁移增益）；集成也仅 +0.0001。**所有模型私榜分数都会 ≈ 0.003**（噪声墙）。

→ **私榜应"稳健优先"，不为边际分数冒超时风险**：
- 私榜分数差异 < 公榜，但**超时置零是毁灭性**的（该步直接 0 分）
- 集成的 +0.0001 不值得冒 CatBoost 慢推理的风险

## 推荐私榜策略（按稳健度）

1. **首选：单种子 tuned LGBM（raw-only，448r×1seed）** —— main.py 简单（无历史循环）、推理最快、≈baseline 精度。`num_threads` 存 4。
2. **次选：官方 baseline LGBM** —— 已验证合规（3.7ms/step），但 main.py 有历史循环（复杂些）。
3. **不推荐：LGBM+CatBoost 集成** —— 私榜超时风险高，公榜已用 CSV 体现了它的价值。
